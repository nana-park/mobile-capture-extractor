# Mobile Capture Extractor

스마트폰 캡처를 판독하고 연속 화면을 묶어 출처와 원본 이미지가 연결된 지식 기록으로 정리하는 **Codex workflow**입니다. 단독 OCR 앱이나 모바일 앱이 아니며, OCR 엔진·자동 동기화 프로그램·Notion 인증을 제공하지 않습니다.

## 기능과 입력·출력

- 입력: 사용자가 지정한 캡처 파일, 적용 프로필, 저장 대상, 선택적인 로컬 처리 원장과 삭제 허용 범위입니다.
- 처리: 신규·변경·중복 판별, 연속 캡처 그룹화, 보이는 원문과 출처 추출, 원본 첨부·재열기 검증, 표·그래프의 파생 크롭, 확인이 필요한 항목 구분입니다.
- 출력: 파일·그룹 목록, 원문과 출처의 확인 수준, 분류 결과, 생성·갱신한 기록, 미완료 항목과 확인 질문, 삭제 여부와 이유입니다.
- 포함된 `pm-job` 프로필은 AI·IT·로봇·모빌리티 자료를 Notion의 주제·키워드·요약·시사점·생각해보기 필드와 원문·실험 상세 본문으로 정리합니다. 프로필을 지정하지 않으면 범용 추출만 수행합니다.

## 설치

저장소 루트를 프로젝트의 `.agents/skills/mobile-capture-extractor`로 복제하거나 전체 내용을 복사하세요. `references/profiles/pm-job.md`의 상대 경로를 유지하고 기존 설치본은 덮어쓰기 전에 비교하세요.

```sh
git clone https://github.com/nana-park/mobile-capture-extractor.git .agents/skills/mobile-capture-extractor
```

Codex에 이미지 판독과 파일 접근 기능이 필요합니다. Notion 저장·원본 첨부에는 사용 가능한 연결 또는 브라우저 접근과 사용자 권한이 별도로 필요합니다. 프로필의 이미지 클립보드 업로드 방식은 실행 환경에 따라 지원되지 않을 수 있습니다. 원본 재열기를 검증할 수 없으면 완료·삭제 처리하지 않습니다.

## 사용 예

```text
$mobile-capture-extractor 지정한 캡처 폴더의 신규 파일 5개를
pm-job 프로필로 정리해줘. 연속 캡처는 묶고 불확실한 링크는 표시해줘.
이번에는 원본을 삭제하지 말고 저장 결과와 검증 상태를 알려줘.
```

```text
$mobile-capture-extractor 이 캡처들을 도메인 분류 없이 추출해줘.
보이는 원문과 요약을 구분하고 잘린 내용은 추정하지 마.
```

## 한계와 원본 처리

흐린 글자, 잘린 문장, 누락된 연속 캡처와 원문 링크는 복원되지 않을 수 있습니다. OCR·분류·요약에는 오류가 있을 수 있어 원본 대조가 필요합니다. 자동 예약 실행이나 동기화는 별도로 구성해야 합니다.

코어는 사용자에게 삭제·삭제 동기화의 명시적 허용을 먼저 요구합니다. 포함 프로필에는 처리 후 삭제와 OneDrive·갤럭시 전파 확인을 전제로 한 규칙이 있으므로 다른 환경에 그대로 적용하지 마세요. 프로필의 자동 삭제 문구 자체는 새 사용자의 삭제 승인이 아닙니다. 삭제를 허용해도 코어의 기록 작성, 원본 첨부·재열기, 대상 일치 검증과 소량 동기화 시험 조건을 먼저 충족해야 합니다. 모호한 파일과 검증 실패 원본은 보존합니다.

캡처 이미지, OCR 결과, 처리 원장, 개인 지원 기록, 실제 저장 대상 식별자와 인증 키는 이 공개 저장소에 커밋하지 마세요.
